# VulnScout

VulnScout is a domain-specific chatbot for software vulnerability intelligence. You ask about a package and version (for example, "Is log4j-core 2.14.1 affected by anything I should patch first?"). It answers with the CVEs that affect that version, whether they are being exploited in the wild, how likely exploitation is, and which version fixes them. Every claim cites the record it came from.

General-purpose LLMs are unreliable here because vulnerability data changes daily and version-range matching is easy to get wrong. VulnScout lets the LLM do the language work: it interprets the question and explains the result. Deterministic tools do the lookups and version comparisons against authoritative live sources:

- [NVD](https://nvd.nist.gov/developers/vulnerabilities) (CVE records, CVSS, CPE configurations)
- [CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) (known exploited vulnerabilities)
- [FIRST EPSS](https://www.first.org/epss/) (exploitation probability)
- [OSV](https://osv.dev/) and [CVE List V5](https://github.com/CVEProject/cvelistV5) (package-level affected version ranges)

This is the final project for INFO 7375 *Semantic Intelligence in LLM* (Northeastern University, Seattle, Fall 2026).
